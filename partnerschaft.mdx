## Partneranforderungen

Wir freuen uns, wenn dein Server mit uns zusammenarbeiten möchte! Um Partner zu werden, musst du folgende Voraussetzungen erfüllen:

<Columns cols={2}>
  <Card title="Mindestens 80 Mitglieder" icon="users">
    Dein Roleplay- oder Community Discord-Server muss aktiv sein und mindestens 80 Mitglieder haben.
  </Card>

  <Card title="Discord ToS & Guidelines" icon="shield">
    Dein Server muss sich vollständig an die Nutzungsbedingungen und Community Guidelines von Discord halten.
  </Card>

  <Card title="Keine NSFW-Inhalte" icon="ban">
    Der Server darf keine nicht-jugendfreien oder expliziten Inhalte enthalten.
  </Card>

  <Card title="Aktive Community" icon="heart">
    Eine engagierte und aktive Mitgliederbasis ist wichtig für eine erfolgreiche Partnerschaft.
  </Card>
</Columns>

## Bewerbungsprozess

<Steps>
  <Step title="Ticket erstellen">
    Öffne ein Support-Ticket in unserem Discord-Server und gib an, dass du dich als Partner bewerben möchtest.
  </Step>
  <Step title="Fragen beantworten">
    Beantworte alle Fragen unseres Teams zu deinem Server, deiner Community und deinen Zielen.
  </Step>
  <Step title="Überprüfung">
    Wir überprüfen deinen Server auf die Einhaltung aller Anforderungen.
  </Step>
  <Step title="Entscheidung">
    Du erhältst eine Rückmeldung, ob dein Server als Partner akzeptiert wurde.
  </Step>
</Steps>

<Tip>
  Stelle sicher, dass dein Server gut organisiert ist und eine positive Community-Kultur hat. Das erhöht deine Chancen auf eine erfolgreiche Partnerschaft!
</Tip>
